# Kai Gao — Quarto Academic Website

## 1. Add your files

Replace these placeholders:

- `images/headshot.jpg` — your headshot
- `files/Kai_Gao_CV.pdf` — your CV

When your papers/slides are ready, put the PDFs in `files/` and replace the
"Paper forthcoming" / "Slides forthcoming" text in `index.qmd` with links such as:

`[Paper](files/Gao_JMP.pdf)`

## 2. Preview

Open a terminal in this folder and run:

    quarto preview

## 3. Publish

The site is published at https://kgao33.github.io using GitHub Pages.
GitHub Pages serves the `docs/` folder on the `main` branch.

After editing the site, rebuild it:

    quarto render

Upload or commit the updated source files and `docs/` folder to the repository.

The site is intentionally one-page and minimal, with a layout inspired by the
academic reference site you provided but with original styling and wording.
